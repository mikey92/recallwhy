# Examples (real runs, not edited)

Each request in `input/` was sent to `POST /run` on the API (`npm run api`) with live Zetaris, Meterless Nightshift and `nvidia/nemotron-3-ultra-550b-a55b`, on 25 Oct 2026 (22:02–22:23 UTC), on the item master whose food lines are real products and whose stores stand at real SNAP supermarket locations, in this order, starting from empty H-MEM and World Model state. `output/example_N.json` is the API's response, unchanged. `output/example_N/` holds the run's full `trace.jsonl`, its `report.html` / `report.md` (open the HTML in a browser), the briefs, the weekly `digest.md` and, for every recall with our stock, the action packet in `actions/<case>/` (pull list, supplier request, customer notice, `packet.json` with the SQL ids). The `trace` and `outDir` paths inside the JSON point at where the files were written in the working copy.

The hosted NVIDIA endpoint answers about 4 calls a minute; the client paces `nvidia/*` calls and retries the rest (`llm.retry` events), and every call got through.
