# Examples (real runs, not edited)

Each request in `input/` was sent to `POST /run` on the API (`npm run api`) with live Zetaris, Meterless Nightshift and `nvidia/nemotron-3-ultra-550b-a55b`, on 26 Oct 2026 (02:04–02:20 UTC), on the item master whose food lines are real products and whose stores stand at real SNAP supermarket locations, in this order, starting from empty agent state (H-MEM, World Model, and in Zetaris an empty `reconciled.supplier_rules` and `reconciled.case_verdicts`). Every run: 0 failed SQL statements. `output/example_N.json` is the API's response, unchanged. `output/example_N/` holds the run's full `trace.jsonl`, its `report.html` / `report.md` (open the HTML in a browser), the briefs, the weekly `digest.md` and, for every recall with our stock, the action packet in `actions/<case>/` (pull list, supplier request, customer notice, `packet.json` with the SQL ids). The `trace` and `outDir` paths inside the JSON point at where the files were written in the working copy.

The runs share what Zetaris holds, so each one starts where the previous one stopped: the supplier barcode rules proven so far (re-proven on all of that supplier's ship notices before they are used) and every verdict so far (a verdict that changes is flagged).
